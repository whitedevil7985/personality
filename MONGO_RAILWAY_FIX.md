# MongoDB / Railway setup

The bot now uses `MONGO_URL` exactly as supplied by MongoDB Atlas. It no longer decodes/re-encodes the URI password.

Railway Variables:

```env
BOT_TOKEN=your_bot_token
MONGO_URL=mongodb+srv://Vanyaxbot:YOUR_ATLAS_PASSWORD@cluster0.0ydl89v.mongodb.net/?retryWrites=true&w=majority&appName=Cluster0
MONGO_DB=ItzVanyaBot
```

If the Atlas password contains special characters, use the exact connection string generated by Atlas, or use the separate variables `MONGO_USER`, `MONGO_PASSWORD`, and `MONGO_HOST`.

In MongoDB Atlas, verify that `Vanyaxbot` exists under Database Access and that the Railway deployment is allowed under Network Access. Never put the real password in this file or in source control.
